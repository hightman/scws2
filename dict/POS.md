# scws2 词性标注

词性是词条自带的元数据，供调用方展示或过滤；当前不参与切分评分，也不进行上下文词性消歧。同一词只有一个标签，不保证它在每个句子中的词性均正确。

## 填写规则

文本词表推荐使用 `词条 词频 词性`，也接受 `词条 词性 词频`。未知或不确定时省略，运行时默认 `un`。标签为一至两个 ASCII 字符，语法为 `[A-Za-z][A-Za-z0-9_-]?`；大小写原样保留，建议使用下表中的小写标签。

```text
大模型 100 n
张三 100 nr
内容管理系统 100 nz
自定义新词
```

离线基础词表允许空标签，XDB2 两个零字节表示缺失；运行时 TEXT 将省略的标签写为 `un`。两者都表示没有可靠标注，不能把 `x` 当作统一的未知值。

## 常用标签参考

这是本项目推荐的填写约定，沿用当前 jieba 基础词表的常见含义，并非完整的统一词性标准。

| 标签 | 含义 | 示例 |
| --- | --- | --- |
| `n` | 普通名词 | 社区、词典 |
| `nr` | 人名 | 张三 |
| `ns` | 地名 | 北京 |
| `nt` | 机构、团体名 | 某公司、某大学 |
| `nz` | 其他专名 | 自定义产品名称 |
| `v` | 动词 | 发布、搜索 |
| `vn` | 名动词 | 研究、管理 |
| `vd` | 副动词 | 使用已有来源的标注 |
| `a` | 形容词 | 清晰 |
| `ad` | 副形词 | 使用已有来源的标注 |
| `an` | 名形词 | 使用已有来源的标注 |
| `d` | 副词 | 已经 |
| `r` | 代词 | 我们 |
| `m` | 数词 | 三、十五 |
| `q` | 量词 | 个、次 |
| `mq` | 数量词组合 | 三个、十五次 |
| `t` | 时间词 | 今天 |
| `f` | 方位词 | 里面 |
| `s` | 处所词 | 某处所词条 |
| `b` | 区别词 | 使用已有来源的标注 |
| `c` | 连词 | 并且 |
| `p` | 介词 | 从 |
| `u` | 助词 | 的 |
| `y` | 语气词 | 吗 |
| `e` | 叹词 | 啊 |
| `o` | 拟声词 | 哈哈 |
| `i` | 成语 | 一心一意 |
| `l` | 习用语 | 习惯性表达 |
| `j` | 简称、略语 | 使用已有来源的标注 |
| `h`, `k` | 前接、后接成分 | 使用已有来源的标注 |
| `g` | 语素 | 使用已有来源的标注 |
| `z` | 状态词 | 使用已有来源的标注 |
| `x` | 非语素等来源分类 | 保留来源含义，不代表未知 |
| `un` | 本项目约定的未知词性 | 省略标签的文本词条 |

现有来源还包含 `ag`、`ng`、`vg`、`dg`、`mg`、`tg`、`rg`、`zg` 等语素细分标签，以及 `df`、`vi`、`vq`、`rr`、`rz`、`ud`、`ug`、`uj`、`ul`、`uv`、`uz` 等细分标签。导入时按原标签保留；本项目没有统一这些细分类别的语义。没有可靠依据时使用基本类别或 `un`，不要凭词面猜测细分类别。

## 来源映射与内置输出

当前基础源见 [sources.lock.json](sources.lock.json)。jieba 的 `nrt`、`nrfg` 在离线加工和运行时 TEXT 加载中均显式归并为 `nr`；其他超过两字符的标签报错，不直接截断。新增来源应先定义明确映射。

内置规则还会返回 `en`（英文/字母串）、`m`（数值）、`mq`（数字加单位）和 `x`（保留的符号）。无词典匹配的未知字、二元兜底片段，其词性仍为空。应结合 token 的 `origin` 与 `kind` 判断来源，不能只凭 `pos` 推断是否命中词典。
