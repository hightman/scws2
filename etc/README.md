# UTF-8 规则数据

- `rules.ini`：原简体 UTF-8 规则。
- `rules_cht.ini`：原繁体 UTF-8 规则。

两者均为 UTF-8，不再通过文件名标注编码。旧的非 UTF-8 规则及编码转换构建流程已删除。

这些文件暂保留原有规则数据用于后续设计，包括 `[attrs]`、人名和地名等节。新核心当前不解析这些 INI，也不会自动套用旧词性倍率、姓名识别或关键词统计参数。重新设计并实现规则支持时再更新此契约。

已移除 `[special]` 和 `[nostats]`：原有 8 个特殊词（`C++`、`C#`、`R&B`、`P&G`、`J++`、`J#`、`UTF-8`、`PS/2`）均由内置英文数字规则完整识别；关键词提取已取消，不再需要统计排除词。内置逻辑标记这些词为 `en`，不复刻旧特殊词规则的 `nz` 标记。当前核心不读取这些 INI，移除两节不会改变现有输出。
