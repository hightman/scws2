# scws2 PHP 扩展

PHP 扩展将命名为 `scws2`，在 UTF-8 核心库与测试稳定后重写，当前目录不包含可构建的 2.0 扩展。

旧扩展依赖已移除的 1.x 接口和字符集切换功能，源码保留在[原 SCWS 仓库](https://github.com/hightman/scws)中。新扩展将薄封装核心 C API，保留词性，不再提供关键词提取或字符集切换。

未来扩展默认使用 `SCWS2_DICT_MMAP`，同时允许调用者显式选择 `0`；这是待实现的接口约定，当前尚无 PHP 封装。

核心分词接口返回独立的 `scws2_result_t`，结果由 `scws2_result_free()` 释放，可支持同一分词对象上的嵌套遍历；未来 PHP 封装需明确管理结果生命周期，错误通过上下文查询。结果只含跨度，封装如需返回词面须同时保存输入字符串。
